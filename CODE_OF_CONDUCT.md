# Code of conduct

GamGUI adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
for everyone taking part — in issues, pull requests, Discussions and anywhere else the project is
represented.

In short: be kind and assume good faith, critique code rather than people, and keep other people's
private details — including the domains and addresses that turn up in admin work — out of public
threads.

## Reporting

If someone's behaviour here bothers you, use **Report content** in the ⋯ menu of the comment,
issue or discussion — that reaches GitHub's staff. The maintainer moderates the threads here too:
hiding, locking or removing what breaks this code and, when needed, blocking the account, following
the Covenant's enforcement guidelines. Anything that involves a leaked credential or a security
problem goes privately through [SECURITY.md](SECURITY.md) instead.
