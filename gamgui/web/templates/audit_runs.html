Reports

Audit runs

Each run is a fixed list of reads of the whole domain, run when you ask, with Stop between its steps. A run changes nothing. Each step is recorded in the Audit log (the command and how many rows, never what it read), and its table is kept here until GamGUI quits or you switch domains. A run can be given a schedule: it then says when it's due, here and on Home, and keeps its last runs on this Mac to say what changed. Nothing runs on its own.
